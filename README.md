# dscrd
just a simple P2P chat system written in HTML. has discord UI

> [!WARNING]
> not encrypted or secured, use with caution

how to use:
1. create room
2. have someone join your room
3. chat

Features Include:
- Very basic profile customization
- Able to send files
- Audio and video call (SOON)
- Typing indicator
- Read/Delivered Messages
- Markdown/formatted messages
- Emoji Picker
- Mentioning system
- GIF search
- Custom status
- Notification sounds
- Edit/Delete messages
- Poll System
- Bots
- Animated avatars
- Offline messages (stores messages and syncs when reconnected)
- Custom Themes
